# Niranjan fly splicing analysis

Inputs: TF and RBP brain workbooks, `All events` sheets. Exact event IDs are deduplicated within each regulator, pooling studies and experiments. Original and new comparisons may overlap; counts do not imply independent evidence. Source flags and experiment details remain in the source files and site table.

Age/sex plots match exact events against the existing fly 3d/6d/9d male-versus-female dataset and its strict-significance flag, using the original fly code. These age comparisons are independent inputs, not the Niranjan sex-limited experiment sheets. The sex-limited sheets are summarized separately by matching event ID and regulator; “female only” and “male only” describe the experiment sets, not proof of sex-specific splicing. The original brain inputs include mixed/unspecified sex and different ages.

The gene charts classify genes by whether at least one regulator-associated event matches a strictly significant age/sex event; the remaining genes have no such match, not proven absence of sex specificity. Tables accompany figures in `tables/`.
